### [ Works Index ]

#### 01 / HOQRUX — Cross-Platform Local-First Media Logbook
`React Native` · `Expo SDK 58` · `TypeScript` · `Supabase (PostgreSQL)` · `TMDB API`
- Architected an offline-ready mobile client built on an asynchronous local-first foundation with instant disk writes via AsyncStorage.
- Implemented background cloud synchronization to Supabase PostgreSQL protected with Row-Level Security (RLS) policies.
- Formulated strict schema models for tracking multi-season television progress, custom user watchlists, and viewing telemetry.
- Source: [github.com/HarshitFreq/HOQRUX](https://github.com/HarshitFreq/HOQRUX)

#### 02 / ShieldSight.ai — On-Device AI Content Moderation Extension
`Chrome Extension (Manifest V3)` · `ONNX Runtime Web` · `React` · `TypeScript`
- Engineered an in-browser neural classification pipeline executing computer vision models on-device via WebAssembly and WebGL.
- Protects user privacy by dynamically detecting and blurring sensitive media directly within the browser sandbox with zero external network transmission overhead.
- Source: [github.com/HarshitFreq/ShieldSight.ai](https://github.com/HarshitFreq/ShieldSight.ai)

#### 03 / SpotifyPlaybackESP32 — Embedded Desktop Controller & Visualizer
`ESP32` · `C++ (PlatformIO)` · `Python Flask` · `Adafruit GFX` · `Spotify Web API`
- Programmed custom hardware firmware driving an Adafruit GFX display pipeline on a 1.3-inch I2C OLED display over a 400kHz fast-bus.
- Implemented a local Python Flask OAuth service to bridge real-time Spotify song states, stream synchronized lyrics via the Lrclib API, and compute an animated 26-bar harmonic audio visualizer.
- Source: [github.com/HarshitFreq/SpotifyPlaybackESP32](https://github.com/HarshitFreq/SpotifyPlaybackESP32)

#### 04 / Clovifi — Contract-Driven Personal Finance Platform
`React` · `Express 5` · `PostgreSQL` · `Drizzle ORM` · `OpenAPI 3.0` · `Orval`
- Developed a pnpm-workspace monorepo financial ledger with atomic balance recalculations on transaction mutations.
- Enforced strict contract-first type safety between Express 5 backend and React frontend via OpenAPI specifications and automated client hook generation.
- Source: [github.com/HarshitFreq/Clovifi](https://github.com/HarshitFreq/Clovifi)

*Additional systems including [Quotidian](https://github.com/HarshitFreq/Quotidian) (WAL habit tracker) and [PromptForge.ai](https://github.com/HarshitFreq/PromptForge.ai) (LLM benchmarker) are available in the [Repositories Index →](https://github.com/HarshitFreq?tab=repositories)*
